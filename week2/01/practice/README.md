# 综合盲写练习：订单统计器

此目录故意不提供 `.go` 文件、函数签名或测试答案。请自行创建实现与测试。

## 数据模型

订单至少包含：订单 ID、客户名称、状态、商品名称 slice、以“分”为单位的整数金额。

状态只允许：

- `pending`
- `paid`
- `cancelled`

## 功能要求

1. 把 JSON 数组解析为订单 slice，并完成业务校验。
2. 空 ID、空客户、非法状态、负数金额均返回错误。
3. 使用 map 检测重复订单 ID，重复时返回错误。
4. 使用 map 统计各状态订单数量。
5. 计算所有非取消订单的总金额。
6. 根据客户名称筛选订单，并返回新的 slice。
7. 定义一个小 interface 表示订单筛选行为。
8. 至少实现“按状态”和“按最低金额”两种筛选器。
9. 将统计结果编码为 JSON。
10. 提供可运行入口，由调用方处理底层返回的错误。

## 测试要求

自行编写测试，至少覆盖：

- 正常解析多个订单。
- 非法 JSON。
- 空字段、非法状态和负数金额。
- 重复订单 ID。
- 状态数量与总金额统计。
- 客户筛选与两种 interface 筛选器。
- 错误发生时不返回部分有效结果。
- 输出 JSON 可以再次解析。
- 测试不依赖 map 遍历顺序。
